# EduBlocks Wildlife Monitor Extension

Custom EduBlocks blocks for a Raspberry Pi wildlife-monitoring lesson using:

- HC-SR501 PIR motion sensor
- DHT22 temperature/humidity sensor
- Raspberry Pi Camera through `rpicam-still`

## Files

- `config.json` — EduBlocks extension configuration
- `definitions.ts` — visual Blockly block definitions
- `generators.ts` — Python generated by each block
- `toolbox.xml` — adds the "Wildlife Monitor" category to EduBlocks

## Blocks

1. **import wildlife monitor libraries**
2. **set up PIR motion sensor on GPIO**
3. **set up DHT22 sensor on GPIO**
4. **wait for motion**
5. **read and display DHT22 temperature + humidity safely**
6. **make timestamped photo filename**
7. **take Raspberry Pi camera photo**
8. **wait until motion stops**

Use EduBlocks' normal blocks for:

- `print(...)`
- `while True:`
- `time.sleep(...)`

The DHT22 read block deliberately contains the `try/except RuntimeError` logic because
the Adafruit DHT library can occasionally raise `RuntimeError` during a sensor read.

## Example target arrangement

Use the custom blocks together with standard EduBlocks blocks:

```python
import time
import subprocess
from datetime import datetime
from gpiozero import MotionSensor
import board
import adafruit_dht

pir = MotionSensor(17)
dht = adafruit_dht.DHT22(board.D4)

print("Wildlife camera is ready!")
print("Waiting for motion...")

while True:
    pir.wait_for_motion()
    print("Motion detected!")

    try:
        temperature = dht.temperature
        humidity = dht.humidity
        print("Temperature:", temperature, "C")
        print("Humidity:", humidity, "%")
    except RuntimeError:
        print("Could not read the DHT22 sensor.")

    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = "/home/pi/photo_" + timestamp + ".jpg"

    subprocess.run([
        "rpicam-still",
        "-o",
        filename,
        "--nopreview"
    ])
    print("Photo saved:", filename)

    pir.wait_for_no_motion()
    print("Motion stopped.")
    print("Waiting for motion again...")
    time.sleep(2)
```

## Importing into EduBlocks

1. Create a public GitHub repository.
2. Put these files at the repository root.
3. In EduBlocks open **Extensions**.
4. Under **Import from GitHub**, paste the repository URL.
5. Click **Import**.

## Raspberry Pi packages

The Pi must already have the Python/hardware dependencies needed by the generated code,
including `gpiozero` and `adafruit-circuitpython-dht`, and the Raspberry Pi camera command
`rpicam-still` must work from the terminal.
